# Panel Multimedia Web

Esta es la versión estática destinada a GitHub Pages. Se sirve por HTTPS para que el reproductor embebido de YouTube reciba un origen web válido.

## Contenido público seguro

- Diseño partido: video a la izquierda y widgets a la derecha.
- Reproductor YouTube embebido de demostración.
- Señal HLS pública de demostración como respaldo con la tecla `1`.
- Hora, clima, titulares y notificaciones locales.

## Antes de publicar

- No agregues URL M3U privadas, credenciales Xtream Codes, tokens ni datos personales a `config.js`.
- El repositorio de GitHub Pages se creará como público porque GitHub Pages expone los archivos publicados.
- Para una futura lista IPTV privada, se usará una configuración distinta que no se subirá a GitHub Pages.

## Operación remota

- `1`: señal HLS de demostración.
- `2`: YouTube embebido.
- `OK`: activa audio, pausa o reanuda.
